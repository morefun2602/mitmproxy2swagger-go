# Triage 标签

技能使用五个标准 triage 角色。本文件将这些角色映射为本仓库 issue tracker 中实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，AFK agent 可直接接手 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色（例如「应用 AFK-ready triage 标签」）时，使用上表中对应的标签字符串。

如需匹配你实际使用的标签命名，请编辑右侧「本仓库标签」列。
